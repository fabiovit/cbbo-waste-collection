# Contribuire

Grazie per l'interesse.

1. Apri prima una issue per bug o modifiche rilevanti.
2. Crea un branch dedicato.
3. Mantieni compatibili gli entity unique ID esistenti.
4. Aggiungi o aggiorna i test.
5. Esegui `python -m compileall custom_components tests` e `pytest`.
6. Apri una pull request descrivendo comportamento precedente, modifica e test eseguiti.

Non includere credenziali, dati personali o materiale di terzi privo di autorizzazione.
